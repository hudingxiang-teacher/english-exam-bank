# 📚 中考英语真题题库系统（本地版）

一套面向中学英语教学的本地化、零依赖、零网络的真题题库系统。**双端独立设计**：学生端专注练习/考试/学情分析；教师端专注题库/试卷/学生/成绩管理。响应式布局，电脑与手机/平板均可访问，**局域网/公网吧内任意终端通过浏览器即可使用**。

## 🚀 快速启动（30 秒开服）


1. 双击 `start.bat`（Windows）或运行 `./start.sh`（Linux/Mac）
2. 等几秒，窗口会显示**访问地址**（如 `http://192.168.1.100:5000`）
3. 把地址发给学生/同事，他们在浏览器打开即可
4. 默认管理员账号：`admin / admin123`（首次登录请改密码）

### 📡 公网吧 / 局域网部署

服务启动后**同局域网所有设备**都能通过浏览器访问：
- 服务器本机：`http://localhost:5000`
- 其他电脑/手机/平板：`http://服务器IP:5000`（如 `http://192.168.1.100:5000`）
- **IP 地址会显示在启动窗口里**，老师直接告诉学生即可

#### 一键搞定网吧/机房环境

| 脚本 | 作用 | 何时用 |
|------|------|--------|
| `start.bat` / `start.sh` | 启动服务 | 每次开机启动 |
| `show_url.bat` / `show_url.sh` | 查看访问地址 | 忘了地址时用 |
| `firewall.bat` | 配置 Windows 防火墙放行 5000 端口 | 第一次部署 / 学生打不开时 |
| `autostart.bat` | 加入 Windows 开机自启 | 网吧服务器需要 7×24 开机 |

#### 网吧/机房部署步骤

1. 把整个 `english-exam-bank` 文件夹放到服务器任意位置（如 `D:\english-exam-bank`）
2. 双击 `firewall.bat` 放行 5000 端口（**右键以管理员身份运行**）
3. 双击 `autostart.bat` 配置开机自启（**右键以管理员身份运行**）
4. 双击 `start.bat` 启动服务
5. 窗口里会显示所有可访问的 IP 地址，把地址写到小纸条上给学生
6. **建议**：在服务器上设置**静态 IP**（避免 DHCP 换 IP 后学生打不开）：
   - 控制面板 → 网络 → 适配器 → IPv4 → 手动设置 IP（如 `192.168.1.100`，子网掩码 `255.255.255.0`，网关 `192.168.1.1`）

#### 学生端使用流程

1. 学生在浏览器输入 `http://老师给的IP:5000`
2. 用自己的账号登录（学生账号由老师创建）
3. 开始练习、看统计、看错题

#### 老师端使用流程

1. 浏览器输入 `http://localhost:5000`（服务器本机）或 `http://服务器IP:5000`（其他电脑）
2. 用 `admin / admin123` 或 `teacher / teacher123` 登录
3. 导入题目、创建学生账号、创建试卷、查看统计

#### 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 学生打不开 | 防火墙没放行 5000 端口 | 服务器上右键 `firewall.bat` → 以管理员身份运行 |
| 显示"无法访问此网站" | 电脑不在同一局域网 | 确认服务器和学生电脑连同一 WiFi/路由器 |
| 启动窗口一关服务就停 | 服务是前台运行 | 网吧服务器用 `autostart.bat` 配开机自启，服务跑在后台；或者最小化启动窗口别关 |
| IP 地址每次启动都变 | DHCP 动态分配 | 服务器手动设置静态 IP |
| 5000 端口被占用 | 其他程序占用了 5000 | 编辑 `app.py` 末尾的 `port=5000` 改为 `5001` 或其他端口 |
| 老师能在自己电脑访问，学生不行 | 服务器 Windows 防火墙拦截 | 运行 `firewall.bat` |

## ✨ 功能一览

### 👨‍🏫 教师端（独立工作台）

  - 创建/编辑试卷：从题库选题

  - 试卷预览、删除

  - 创建账号（学生/教师/管理员）

- **历史记录**：所有练习/考试记录，可回顾每一道题的答题情况

## 🚀 快速开始

### 一键启动（Windows）

1. **安装 Python 3.8+**（https://www.python.org/downloads/）
   - 安装时务必勾选 **"Add Python to PATH"**

2. **解压本程序到任意目录**（推荐 `D:\english-exam-bank`）

3. **双击 `start.bat`**
   - 首次运行会自动安装 Flask 和 openpyxl（需联网一次）
   - 启动后浏览器会自动打开 http://localhost:5000

4. **局域网内其他电脑/手机访问**：
   - 查看终端/控制台窗口显示的 IP（如 `http://192.168.1.100:5000`）
   - 在其他设备的浏览器输入该地址即可

5. **停止服务**：双击 `stop.bat`，或直接关闭终端窗口

### Mac / Linux

```bash
cd english-exam-bank
chmod +x start.sh stop.sh
./start.sh
# 停止
./stop.sh
```

### 手动启动（任意系统）

```bash
# 1. 安装依赖（仅首次需要）
pip install flask openpyxl

# 2. 启动
python app.py

# 3. 浏览器访问
# 本机: http://localhost:5000
# 局域网: http://你的IP:5000
```

## 📝 使用流程

### 第一次使用
1. 用 `admin / admin123` 登录
2. **导入题目**：
   - 进入「题库管理」 → 「批量导入」→ 选择 `data/sample_questions.json`（已附 15 道样题）
   - 或在「题库管理」中点「手动录入」
3. **创建班级**：进入「题库管理」中切换或直接在「学生管理」时选择默认班级
4. **创建学生账号**：「学生管理」→「新增账号」→ 角色选「学生」→ 分配班级
5. **（可选）创建试卷**：「试卷管理」→「新建试卷」→ 从题库选题 → 设置时长/总分 → 发布
6. **学生登录**：学生在自己电脑/手机浏览器输入服务器地址，用分配的账号登录

### 学生日常使用
1. 登录后看到「学习中心」
2. 点「自由练习」选数量开始
3. 答错题自动加入错题本
4. 点「学习报告」看自己的进步
5. 老师发布考试后，进入「考试中心」参加考试

### 教师日常使用
1. 登录后看到「工作台」，总览全站数据
2. 持续导入题目扩充题库
3. 期中/期末前在「试卷管理」创建试卷
4. 考试结束后在「成绩分析」查看班级整体表现、试卷难度、每道题的区分度

## 📊 题目导入格式

### JSON 格式
```json
[
  {
    "qtype": "单选",
    "stem": "She ___ to school every day.",
    "options": [
      {"label": "A", "content": "go"},
      {"label": "B", "content": "goes"},
      {"label": "C", "content": "went"},
      {"label": "D", "content": "going"}
    ],
    "answer": "B",
    "kp": ["KP_GRAMMAR_TENSE"],
    "difficulty": 2,
    "score": 2,
    "source": "2023 北京中考",
    "year": 2023,
    "analysis": "主语是第三人称单数，一般现在时用 goes。"
  }
]
```

### Excel 格式（.xlsx）
| 列 | 必填 | 说明 |
|----|------|------|
| qtype | ✅ | 题型（单选/多选/完形填空/选词填空/阅读理解/翻译/作文）|
| stem | ✅ | 题干 |
| answer | ✅ | 答案（单选填 `A`；多选填 `A,B,D`）|
| option_a | | A 选项内容 |
| option_b | | B 选项内容 |
| option_c | | C 选项内容 |
| option_d | | D 选项内容 |
| option_e | | E 选项内容 |
| option_f | | F 选项内容 |
| kp | | 知识点编码，多个用 `;` 分隔 |
| difficulty | | 难度 1-5 |
| score | | 分值，默认 2 |
| year | | 年份 |
| source | | 来源 |
| analysis | | 解析 |

### CSV 格式
字段同 Excel，首行表头。

## 🛠️ 常见问题

### Q1: 双击 start.bat 闪退？
**A**: 大多数情况是 Python 未安装或未加入 PATH。  
- 打开 cmd 输入 `python --version` 验证  
- 若提示"不是内部或外部命令"，重新安装 Python 并勾选「Add Python to PATH」

### Q2: pip 安装很慢或失败？
**A**: `start.bat` 已使用清华镜像，如仍失败可手动指定：
```bat
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple flask openpyxl
```

### Q3: 端口 5000 被占用？
**A**: 打开 `start.bat`，把 `PORT=5000` 改成 `PORT=5050` 即可（前端不用改）。

### Q4: 局域网内其他设备访问不到？
**A**: 
- 确认服务端电脑防火墙允许 5000 端口
- Windows：「控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP 5000」
- 路由器/家庭网络通常无需额外设置

### Q5: 数据备份？
**A**: 复制 `data/exam.db` 文件即可。这就是全部数据。

### Q6: 改默认密码？
**A**: 用 admin 登录后，「学生管理」里找到对应账号 → 编辑或重置密码。
